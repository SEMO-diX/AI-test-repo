# Experiments

This directory is for bounded, public-safe engineering experiments created by the Personal Engineering Harness.

Each durable experiment should make its own question and evidence understandable without requiring access to private memory.

Recommended contents for an experiment directory:

- `README.md` — question, hypothesis, method, outcome, limitations;
- implementation or prototype files;
- automated tests when practical;
- reproducible verification commands.

Do not store private user context, raw private-memory records, credentials, or source data that does not belong in a public repository.

Temporary local artifacts should remain untracked.
